# Composition regression oracles

`tabs.xml` is a synthetic Hub document. The worked expectations in
`CompositionTest.checkContract` come from the public tabs-to-indent contract:
20 twips per point, one identifier per list marker, unchanged equation content,
and 12pt = 240 twips for the figure margin. The caller explicitly tunnels an
internal tab into `remove-nodes`; its disappearance proves `xsl:next-match`
reached the imported tab template. Simply copying the input cannot pass.

`expected-indent.xml` and `expected-role.xml` were generated by real importing
callers against unmodified source base
`01ebac179ff6425214fb5f3cab79c25771da214b`. Both callers import the combined root
for shared context before importing their original standalone entry. Maintained
outputs must match those original bytes, including namespace declarations and
whitespace. Compiling an isolated raw module still fails for missing shared
context before and after this change; the raw-module test preserves that limit.

`frozen-input.xml` and `expected-frozen.xml` retain a synthetic compatibility
case and its frozen tabs-to-indent serialization. The maintained combined root
is executed afresh and compared byte for byte. The source-owner driver was also
executed independently with this synthetic input and produced these same bytes.
The public caller captures the relevant import, initial mode and serialization
settings without requiring an application-specific driver.

The combined graph must compile without Saxon's `SXWN9019` duplicate-module
diagnostic. The original base emits this diagnostic for both `tabs-to-indent`
and `hub-functions`; the maintained composition removes those duplicate paths.
This assertion inspects a real compiler diagnostic, not stylesheet source text.
Standalone callers may still report duplicate imports from their deliberate
composition with the shared root; their raw diagnostics are retained.

For build prerequisites and commands, see the [project README](../README.md).
No warning baseline or suppression is added for the Kotlin harness. These
focused regressions do not claim complete XProc or corpus validation.
